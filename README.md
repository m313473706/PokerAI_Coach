# Poker AI Coach — Windows 屏幕采集版

> **当前分支不是可安装交付版。** 牌面 OCR 已关闭；因尚无许可已核实的牌面模型，当前构建会拒绝生成安装器。

此分支只保留 Windows 牌桌窗口采集和界面文字识别；由于还没有合规的牌面视觉模型，牌面不会被识别，也不会计算牌型、胜率或行动建议。主界面不提供手动输入手牌或牌局数据的分析入口。

## 主要功能

- 自动列出可见窗口，并优先使用 Windows Graphics Capture 按窗口句柄直接采集牌桌；遇到黑屏或不兼容时检测并回退到屏幕区域截图。
- 在本机运行 RapidOCR 读取底池、下注、按钮等界面文字；OpenCV 轮廓仅定位可疑牌区，不识别牌值。
- 只有来自牌面视觉模型的完整点数与花色、稳定且无重复牌时，才允许牌型与行动分析。当前仓库未包含该模型，因此分析会安全停止。
- 用本地蒙特卡洛抽样估算对随机对手的胜率。
- 当画面同时读到底池和跟注金额时计算跟注所需胜率，并给出带条件的教练提示。
- 导出识别 JSON 和对应截图，便于检查画面识别结果。
- OCR 字符不会作为牌面识别结果；未知点数、未知花色、低置信度或重复牌都会阻止行动建议。

## 安装与启动

1. 从 GitHub Actions 的成功构建页面下载 PokerAI_Coach_Ultimate_Windows。
2. 解压后运行 PokerAI_Coach_Ultimate_Setup.exe。
3. 按中文安装向导完成安装，从桌面或开始菜单启动 Poker AI Coach。
4. 打开扑克模拟器，在程序中点“刷新窗口”，选中牌桌窗口后点“开始实时识别”。
5. 需要留档时点“导出识别记录”。

视觉识别、牌型计算和胜率估算均在本机完成，屏幕画面不会自动上传。

## 使用边界

胜率以“对手持随机两张手牌”为基准，不等同于已知对手范围或专业求解器结果；只有 OCR 同时识别出底池和跟注金额时才比较底池赔率。每款模拟器的画面、牌背、主题、缩放比例和显卡绘制方式可能不同。此分支的 CI 会先验证牌面安全闸门，并在模型文件缺失时拒绝打包；目前还没有真实样例预测结果或目标模拟器实测。

## 技术启动

开发运行环境为 Windows 和 Python 3.11。安装 requirements.txt 后运行 python app.py。
