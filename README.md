
# Poker AI Coach 0.3.2 Stable

这是扑克训练/复盘模拟软件，不用于真实资金牌局。

## 运行
Windows:
双击 `run_windows.bat`

Python:
`python app.py`

## 0.3.2 内容
- 中文局面分析器
- 牌力
- 简化对手范围
- Blocker
- Monte Carlo 胜率
- 估算 Outs
- Pot Odds
- Break-even Equity
- SPR
- Call EV
- 简化行动 EV
- 牌面结构
- 异常输入处理

## 模型限制
本版本是训练用途的简化模型，不是完整 GTO Solver。
