# Poker AI Coach（Windows）

这是 Windows 桌面版 Poker AI Coach。它把牌桌画面识别候选与原有德州扑克分析器放在同一个应用中：先抓取模拟器窗口或打开录屏，再核对手牌、公共牌和 BB 金额，最后查看牌力、估算胜率、底池赔率、SPR、补牌和简化 EV 对比。

## 安装与启动

1. 从 GitHub Actions 最近一次成功的 **Build Poker AI Coach Windows** 构建中下载 `PokerAI_Coach_Windows` 压缩包。
2. 将整个压缩包解压到一个普通文件夹。
3. 双击 `PokerAI_Coach.exe`。无需单独安装 Python。
4. 首次识别时打开模拟器，点“刷新模拟器窗口”，选中窗口后点“抓取选中窗口”。也可以用“打开视频”分析录屏。
5. 点“分析当前帧”，再点“分析已核对局面”。对照画面核对自动填入的牌；手动填写底池、跟注和有效筹码（单位均为 BB），确认对手位置与行动后再运行分析。

分析页面会在候选牌不完整或输入无效时提示修正。保存的识别结果默认放在“文档\PokerAI_Recognition_Output”。

## 主线与组成

唯一主线是本仓库 `main` 分支。德州扑克分析继续使用原有 0.3.2 分析核心；0.7 包中的牌面、金额和可见行动识别模块作为输入候选接入同一桌面应用。`PokerAI_Recognition_Validation_0_7` 保留为视觉识别与 OCR 运行环境的验证来源，不作为整合产品。

## 使用范围与已知限制

- 视觉识别输出是单帧候选，需要用户对照画面核对；金额、跟注额和有效筹码不会自动视作已确认。
- 当前 Windows 构建自检证明 OCR 引擎在打包程序中能够加载并处理固定样本，不等于已通过真实模拟器的实时识别验收。真实模拟器端到端识别尚未验证。
- 牌局分析使用简化训练范围、Monte Carlo 胜率和近似下注 EV，不等同于 GTO 求解器。

## Windows 构建验证

GitHub Actions 会运行源代码单元测试、固定样本 OCR 自检、单文件程序 OCR 自检，再生成无需 Python 环境的 Windows GUI 程序和压缩包。
