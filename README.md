# Poker AI Coach — 终极 Windows 屏幕视觉版

这是 Poker AI Coach 的唯一主线交付。程序自动采集选定的 Windows 牌桌窗口，识别牌面与画面文字，并在识别稳定后计算牌型和对随机对手的胜率基准。主界面不提供手动输入手牌或牌局数据的分析入口。

## 主要功能

- 自动列出可见窗口并持续采集所选窗口；优先使用 Windows 窗口绘制接口，失败时回退到屏幕区域截图。
- 在本机运行 RapidOCR 与图像检测，显示牌区、识别文字和连续帧稳定情况。
- 对两张手牌和公共牌识别结果进行牌型计算。
- 用本地蒙特卡洛抽样估算对随机对手的胜率。
- 当画面同时读到底池和跟注金额时计算跟注所需胜率，并给出带条件的教练提示。
- 导出识别 JSON 和对应截图，便于检查画面识别结果。
- OCR 能识别点数但未读出花色时，胜率会对缺失花色进行随机估算，并明确标注；点数不清或重复牌时停止分析。

## 安装与启动

1. 从 GitHub Actions 的成功构建页面下载 PokerAI_Coach_Ultimate_Windows。
2. 解压后运行 PokerAI_Coach_Ultimate_Setup.exe。
3. 按中文安装向导完成安装，从桌面或开始菜单启动 Poker AI Coach。
4. 打开扑克模拟器，在程序中点“刷新窗口”，选中牌桌窗口后点“开始实时识别”。
5. 需要留档时点“导出识别记录”。

视觉识别、牌型计算和胜率估算均在本机完成，屏幕画面不会自动上传。

## 使用边界

胜率以“对手持随机两张手牌”为基准，不等同于已知对手范围或专业求解器结果；只有 OCR 同时识别出底池和跟注金额时才比较底池赔率。每款模拟器的画面、牌背、主题、缩放比例和显卡绘制方式可能不同。GitHub CI 会检查本机 OCR 模型、牌型算法和安装包构建，但它不能代替在目标模拟器中的真实牌桌验证。请把识别结果视为辅助信息，并核对低置信度字段。

## 技术启动

开发运行环境为 Windows 和 Python 3.11。安装 requirements.txt 后运行 python app.py。
