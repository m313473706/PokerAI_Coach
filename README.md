# Poker AI Coach — Windows 屏幕采集版

> **当前是 Poker AI Coach 1.0 RC 工作分支，尚未达到可安装交付状态。** 牌面识别正在自研；训练工作流只产出候选模型。目标模拟器截图回放通过之前，不生成最终安装器。

## 当前实现

- 自动列出可见窗口，通过 Windows Graphics Capture 采集牌桌；遇到黑屏或不兼容时回退到窗口绘制或屏幕区域。
- 在本机运行 RapidOCR 读取底池、下注和操作文字。
- 轮廓算法定位牌框，本地 ONNX 分类器逐张预测点数和花色。模型从随机初始化训练，不使用云端识牌 API。
- 只有牌值完整、置信度与类别差距达标、没有重复牌，且整手牌连续三帧一致时，才允许牌型与行动分析。
- 用本地蒙特卡洛抽样估算对随机对手的胜率，并在读到底池和跟注金额时计算跟注所需胜率。
- 导出识别 JSON 与对应截图，便于检查识别结果。

当前分支尚无已提交模型权重和真实截图回放报告，所以程序不会给出基于识牌的行动建议。不能把模型训练 workflow 的候选 artifact 当作可安装程序。

## 自研模型

训练使用固定提交的 [CC0 扑克牌素材](https://github.com/safe-acid/Playing-cards-assets/tree/ae925833a28f587ec6abed561822889eb044a18c)，从随机初始化训练 52 类分类器。训练、推理和牌局分析均在本地执行；运行时不需要付费识牌 API。模型和数据来源详情见 [MODEL_CARD.md](MODEL_CARD.md) 与 [MODEL_STATUS.md](MODEL_STATUS.md)。

GitHub Actions 中的 `Train in-house card classifier` 工作流会生成 90 天可下载的**候选模型**和训练报告。工作流里的合成验证准确率只代表同一套牌面图的合成变换效果，不代表目标模拟器识别率。

最终 Windows 打包还要求对目标模拟器实截图进行回放：标注至少覆盖 52 种牌，轮廓定位与分类结果全部正确，无额外牌框、漏检或低置信度拒绝。使用 `replay_card_screenshots.py` 生成报告；报告记录模型 SHA-256，确保验收对象和安装器中的权重相同。清单格式和命令见 [MODEL_STATUS.md](MODEL_STATUS.md)。

## 安装与启动

目前没有可供下载的最终 Windows 安装包。不要把候选 ONNX artifact 当作发行版使用。模型回放及 Windows 自检通过后，才会由构建 workflow 生成安装包。

开发运行需要 Windows 与 Python 3.11。安装 `requirements.txt` 后运行：

```powershell
python app.py
```

本地牌面识别还需要将训练工作流产出的候选模型放入 `models/playing_cards.onnx`；未安装模型时，程序只会报告牌面模型不可用，并停止行动建议。

## 使用边界

胜率以“对手持随机两张手牌”为基准，不等同于已知对手范围或专业求解器结果。模拟器主题、缩放比例、遮挡和显卡绘制方式都会影响画面识别。合成契约检查验证软件安全路径；合成训练准确率验证训练素材上的分类表现；只有目标模拟器截图回放和本机现场运行才能验证最终识牌效果。
