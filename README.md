# Poker AI Coach — Windows 屏幕采集与视觉理解

这是 Poker AI Coach 的 Windows 视觉主线。程序不要求手动填写手牌或牌局参数，而是枚举可见窗口、采集所选窗口画面，并在本机识别牌面区域、文字、行动词和金额候选。

## 当前功能

- 实时读取所选 Windows 窗口画面并显示预览。
- 用本机 RapidOCR 提取画面文字及位置。
- 用图像区域检测定位疑似扑克牌，再识别卡牌左上角文字。
- 连续帧跟踪候选牌，显示识别稳定性。
- 导出当前识别结果 JSON 和对应截图。
- 未识别字段保留为候选，不凭空补值。

## 安装和启动

1. 下载 Windows 构建包并解压到普通文件夹。
2. 双击 PokerAI_Coach.exe。
3. 打开扑克模拟器；在程序里点击“刷新窗口”。
4. 选择模拟器窗口并点击“开始实时识别”。
5. 需要留存结果时点击“导出识别记录”。

## 识别范围和限制

画面采集与 OCR 在本机完成。牌区定位使用通用图像规则，牌面文字使用 OCR；不同模拟器、主题、缩放和窗口布局会影响识别率。程序当前展示的是视觉候选和稳定度，不会把未确认的信息伪装成准确牌局状态，也不会基于不完整状态给出策略建议。

Windows CI 只验证依赖、模型加载及 EXE 打包，不代表已经在真实扑克模拟器上完成实时识别验证。请将目标模拟器的真实画面采集结果用于后续校准。

## 源码运行

使用 Python 3.11，在项目目录安装 requirements.txt 中的依赖后运行 app.py。正式使用建议直接运行 Windows 构建包中的 EXE。
