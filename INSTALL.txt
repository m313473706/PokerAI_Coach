Poker AI Coach — 终极 Windows 屏幕视觉版
安装说明

一、安装
1. 下载并解压 PokerAI_Coach_Ultimate_Windows 构建包。
2. 双击运行 PokerAI_Coach_Ultimate_Setup.exe。
3. 按中文安装向导完成安装。
4. 从桌面快捷方式或 Windows 开始菜单启动 Poker AI Coach。

二、开始实时识别
1. 先打开扑克模拟器，并让牌桌保持可见。
2. 在 Poker AI Coach 中点击“刷新窗口”。
3. 在窗口列表中选择扑克模拟器，点击“开始实时识别”。
4. 等待自己的两张牌与公共牌连续稳定识别；右侧会显示牌型、随机对手胜率基准及可计算时的底池赔率提示。
5. 点击“停止”结束采集；点击“导出识别记录”保存 JSON 与对应截图。

三、重要说明
- 程序主界面不需要手动输入手牌或牌局数据。
- 识别和分析在本机完成，不会自动上传牌桌截图。
- 对手胜率使用随机手牌作为基准；未能同时读到底池与跟注金额时，不会给出具体跟注动作。
- 不同模拟器可能需要后续针对画面布局校准。首次使用请核对识别结果。
- Windows 可能提示未知发布者；请确认文件来自本项目的成功 GitHub Actions 构建后再运行。
