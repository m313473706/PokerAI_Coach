Poker AI Coach Windows 版本

普通使用者无需自行安装 Python：请从 GitHub Actions 最近一次成功的 “Build Poker AI Coach Windows” 构建下载 PokerAI_Coach_Windows.zip，解压后运行 PokerAI_Coach.exe。

如需从源码运行，请安装 Python 3.11，运行 run_windows.bat。脚本会安装 requirements.txt 中的依赖并启动程序。

如需重新构建 EXE，请在 GitHub 仓库的 Actions 页面运行 “Build Poker AI Coach Windows”。构建会先运行现有测试和 OCR 运行自检，再上传 Windows 压缩包。

识别候选必须由用户核对。CI 中的 OCR 自检只证明 OCR 引擎可在打包程序中加载并处理固定样本，不代表真实扑克模拟器已通过实时识别验收。
